What these results cannot tell you

  • The client is a GitHub-hosted runner whose location is not controlled, so latency includes that network path. Compare targets within one run, not across runs.
  • Sizes are the closest each provider offers, not identical. The size column is exact.
  • One instance is not how you would run production; it isolates the platform, not the autoscaler.
  • Railway builds the Dockerfile itself, so its image digest differs from the others.
  • Prices change; cost per run is recorded in each target's ADR with the date it was checked.

What each number means

Deploy
Seconds from starting the deploy to the provider reporting it done.
Ready
Seconds from the deploy finishing to the first healthy /health.
Sequential p50 / p95
Latency of one-at-a-time requests, in milliseconds (median and 95th percentile).
Load requests/s and p95
Throughput and 95th-percentile latency (ms) of the item endpoint under concurrent load.
CPU requests/s
Throughput of the CPU-bound endpoint under the same load.
Errors
Share of failed requests during the item load test.

What these results cannot tell you

  • The client is a GitHub-hosted runner whose location is not controlled, so latency includes that network path. Compare targets within one run, not across runs.
  • Sizes are the closest each provider offers, not identical. The size shown is exact.
  • One instance is not how you would run production; it isolates the platform, not the autoscaler.
  • Railway builds the Dockerfile itself, so its image digest differs from the others.
  • Prices change; cost per run is recorded in each target's ADR with the date it was checked.
